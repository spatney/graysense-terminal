# Changelog

Each version's section is its release notes: on GitHub, and in Graysense's "What's new" when an
update is ready.

## 0.1.0 — 2026-11-12

The first release of Graysense: a fast, flat terminal for GitHub Copilot agents, written in Rust on
the Copilot SDK.

- **Native Copilot agents**: streaming replies, inline approvals, native forms for questions and
  plans, model and mode pickers, steering, and file attachments.
- **Sessions**: every session gets its own folder. A sessions sidebar to pin, rename and delete them,
  and search (Ctrl+K) across conversations and files.
- **Canvases and MCP Apps**: checklists, tables, dashboards and documents beside the conversation,
  and interactive UIs from MCP servers.
- **Real terminals**: your shell through ConPTY, with GPU text rendering.
- **Mission board**: capture ideas, then delegate them to agents.
- **Memory**: agents learn your preferences and each project's conventions. See and edit what they
  learn, or turn it off.
- **Ask agents to set things up**: they can change any setting, MCP server or plugin for you.
- **Installer and updates**: a one-click installer for your account. New versions download in the
  background and install when you restart Graysense.
